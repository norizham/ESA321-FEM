Learn the 2D Truss Element

This module follows the ESA 321 truss lecture: truss assumptions, two translational DOFs per node, direction cosines, element stiffness in the global reference frame, assembly, boundary conditions and solution.

Truss behaviour

Global assembly

For n nodes, the total number of structural DOFs is 2n. Map each element's four DOFs into the matching global rows and columns and add overlapping contributions.

6

Boundary conditions

Apply prescribed u and v values at supports, solve the reduced system for free nodal displacements, then recover reactions from the original global equation.

Practice · Three-Member Truss

Use the practice problem from the lecture notes: determine the horizontal displacement of node 1. The structure has three members, A = 0.05 m², E = 20 × 10⁶ N/m², a 500 N horizontal load at node 1, and the dimensions shown in the lecture diagram.

Determine: the element direction cosines, element stiffness matrices, assembled global stiffness matrix, horizontal displacement of node 1, and support reactions.

Hint 1: assign global DOFs (u, v) to all four nodes and calculate each member length from the geometry before evaluating l and m.
Hint 2: nodes 2, 3 and 4 are supports. Apply their prescribed displacements before solving for the free DOFs at node 1.
