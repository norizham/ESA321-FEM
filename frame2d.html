1. Frame Model

Standard 2-node Euler–Bernoulli plane-frame element. Each node has three DOFs: horizontal displacement u, vertical displacement v, and rotation θ.

2. Node Coordinates

Nodex (m)y (m)

3. Element Connectivity

Element-specific section property: enter a separate cross-sectional area Aₑ for each element.

ElementNode iNode jArea Aₑ (m²)

4. Frame Structure

θ is measured counter-clockwise from global +X in the Node i → Node j direction.

5. Frame Element Formulation

Local element DOF order:

{d′}(e) = {u′ᵢ, v′ᵢ, θᵢ, u′ⱼ, v′ⱼ, θⱼ}T
Local stiffness matrix: combines axial stiffness AE/L and bending stiffness EI/L³.
[k](e) = [T]T[k′](e)[T]

Global element DOF order: {uᵢ, vᵢ, θᵢ, uⱼ, vⱼ, θⱼ}. Direction cosines: l = cos θ, m = sin θ.

6. Interactive Assembly Teaching Mode

Select an element to highlight the member, its six global DOFs, and its locations in the assembled global stiffness matrix.

Calculate the frame, then select an element.

8. Assembled Global Stiffness Matrix [K]

Global DOF order: u₁, v₁, θ₁, u₂, v₂, θ₂, ... . Boundary conditions are not applied.
