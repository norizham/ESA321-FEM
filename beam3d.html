1. 3D Beam Model

This page uses the standard 2-node Euler–Bernoulli 3D beam/frame element. Each node has 6 DOFs: three translations and three rotations.

DOFs at each node: {u, v, w, θx, θy, θz}. The local x-axis runs from Node i → Node j. A reference vector is used to establish the local y-z orientation and avoid ambiguity about section rotation.

5. 3D Beam Element Formulation

{d′}(e) = {uᵢ, vᵢ, wᵢ, θxᵢ, θyᵢ, θzᵢ, uⱼ, vⱼ, wⱼ, θxⱼ, θyⱼ, θzⱼ}T
G =E2(1+ν)
[k](e) = [T]T[k′](e)[T]

[k′] is the 12×12 local stiffness matrix containing axial EA/L, torsional GJ/L, bending about local y using EIᵧ, and bending about local z using EI𝓏.
