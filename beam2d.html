1. Beam Model

This page uses the standard 2-node Euler–Bernoulli bending element. Each node has two DOFs: transverse displacement v and rotation θ. Cross-sectional area Aₑ is stored per element for section definition; in this pure Euler–Bernoulli bending formulation the stiffness depends on E, Iₑ and L, so Aₑ does not change the bending stiffness.
